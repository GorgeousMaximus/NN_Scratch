# Neural Network from Scratch

A small neural network library built from scratch using NumPy. No PyTorch, no autograd. This is a project for my Boot.dev Journey and is my first self led piece of work while following their courses. My aim is to implement a small neural network training program on EMG data as I have a historical interest in neuroprosthetics research.

## Install
I believe the easiest way to run this is to us uv as a package manager as I did in writing the project
- clone the repo
- ```uv sync```
- ```uv run train.py```
At the current time of writing this the project is a skeleton so if you come across it, there isn't actually anything to run yet...
